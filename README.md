# system-widget

Windows 向けのデスクトップ常駐型システムモニターウィジェットです。CPU 使用率・メモリ使用量・Wi-Fi / Ethernet 接続情報・ネットワークトラフィックをリアルタイムで表示します。

![Go](https://img.shields.io/badge/Go-1.25-00ADD8?logo=go&logoColor=white)
![Windows](https://img.shields.io/badge/Windows-only-0078D6?logo=windows&logoColor=white)

> **v2.0 で、Claude / Codex の使用量モニター（旧 [ClaudeMonitor](https://github.com/ShuheiKonno/ClaudeMonitor)）を取り込みました。** v2.0.0 はプレリリース、v2.0.1 から正式版です。従来どおりの動作だけでよい場合は v1.9.3 を使えます。AI 使用量は既定で OFF なので、ON にしない限り、認証用の WebView2 の起動も、取得も行いません (画面には、区画の折りたたみボタン ▼ が加わります)。

## 機能

- **CPU モニタリング** — 全体使用率 + コアごとの使用率をバーグラフで表示。モデル名も表示 (フル表示時のみ)
- **CPU クロック周波数** — 現在の実効クロックを表示。ベースクロックに対する位置をバーで示す。バーの色は、電源モードではなく、ベースクロックとの差で決まる (ベース -10% 〜 +20%: 青 / -11% 以下: 緑 / +21% 以上: オレンジ)
- **電源モードの切替** — CPU 区画のスライダーで、Windows 設定アプリの「電源モード」(最適な電力効率 / バランス / 最適なパフォーマンス) を「省電力」「バランス」「パフォーマンス」の 3 段階で切り替え。ドラッグして離したとき (ラベルのクリックや ←→ キーでも) に切り替わる。スライダーの色も電源モードで変わる (省電力: 緑 / バランス: 青 / パフォーマンス: オレンジ。つまみの位置までを塗る)。設定アプリでの変更にも追従する。電源接続時とバッテリー駆動時は別々に記憶され、今使っている側だけを操作する。電源プランが「バランス」以外のときは効かないため無効表示になる。コンパクト表示では非表示。**既定では無効 (OFF)** で、設定 ⚙ の「電源モードの切替」を ON にしたときだけスライダーが出る。OFF のときは、電源モードの読み取りも切り替えも一切行わず、Windows の設定・制御のままになる (スライダーは非表示)。電源モード自体は OS の状態なので、アプリの設定としては保存しない (ON/OFF の設定だけを保存する)。Windows の非公開 API (`PowerSetActiveOverlayScheme` など) を使うため、将来の Windows 更新で動かなくなる可能性がある (使えない環境ではスライダーごと非表示)
- **メモリモニタリング** — 使用率・使用量 / 総容量を表示
- **Disk モニタリング** — 固定ドライブ (C: / D: …) の合計使用率とドライブ別の使用量 / 総容量 (使用率 90% 以上は警告色)、物理ディスク全体の Disk I/O (アクティブな時間・読み取り・書き込み速度) を表示。区画をクリックすると、表 (使用量) と裏 (I/O) が 3D 反転で切り替わる。I/O の見せ方は ⚙ で「数値」(既定) か「グラフ」(読み取り / 書き込みの折れ線、直近 2 分) を選べる。使用量は 10 秒ごと、I/O は 2 秒ごとに更新する。コンパクト表示と折りたたみ中は見出しだけで、表は合計使用率、裏はアクティブな時間。⚙ で非表示にすると収集も止まる (切断済みのネットワークドライブや空の光学ドライブは対象外)
- **GPU モニタリング** — 使用率 (タスクマネージャーと同じ全エンジン最大値) と専用・共有メモリを別々に表示。専用容量 512 MiB 以上の GPU を優先し、複数ある場合は最大容量のものを、該当しない場合は iGPU を自動選択。モデル名も表示 (フル表示時のみ)
- **NPU モニタリング** — NPU がある場合に使用率とモデル名を表示 (NPU 未搭載の PC ではセクションごと非表示)
- **Wi-Fi 情報** — SSID・帯域 (2.4GHz/5GHz/6GHz)・規格 (Wi-Fi 4〜7)・信号強度・チャネル。アダプタのモデル名も表示 (フル表示時のみ)
- **Ethernet 情報** — Wi-Fi 未接続時に有線 NIC を自動検出し、アダプタ名とリンク速度 (10Mbps / 100Mbps / 1Gbps / 2.5Gbps / 5Gbps / 10Gbps) を表示。アダプタのモデル名も表示 (フル表示時のみ)。ドライバが `995Mbps` のように報告する場合も標準値にスナップ
- **ネットワークトラフィックグラフ** — Wi-Fi/Ethernet セクションをクリックすると 3D 反転で裏面に切替、送受信スループットを折れ線グラフで表示 (直近 2 分)。ヘッダのピーク値をクリックすると `KB/s` ⇔ `Mbps` の単位切替。コンパクト表示と Wi-Fi / Ethernet 区画の折りたたみ中はグラフを隠し、現在の合計スループット (↓+↑) を表示 (折りたたみ中も区画のクリックで反転できる)
- **AI 使用量 (Claude / Codex)** — Claude Code と OpenAI Codex（サブスクリプションプラン）の 5 時間枠・7 日枠の使用率とリセット時刻、プラン、追加利用枠 / クレジット残高、サービス障害を、既存の区画の下に表示 (v2.0.0〜。既定は OFF、設定 ⚙ で ON)。詳しくは「[AI 使用量](#ai-使用量-claude--codex)」
- **区画の折りたたみ** — CPU・メモリ・GPU・NPU・Wi-Fi・AI の各見出しの右端の ▼ で折りたたみ・展開。折りたたむと見出しだけが残り、値は見える。状態は保存され、AI は既定で折りたたみ (v2.0.0〜)
- **AI 使用量の折りたたみ / コンパクト時の表示切替** — ⚙ の「折りたたみ / コンパクト時の表示」で、Claude と Codex の見せ方を選べる。「並べて表示」(既定、2 行)、「自動で反転」(1 行ずつ、約 4 秒ごとに反転して入れ替え)、「クリックで反転」(1 行ずつ、クリックで入れ替え。Wi-Fi 区画と同じ操作)。反転表示は折りたたみ時も見出し「AI 使用量」と同じ 1 行の中に収め、コンパクト時も 1 行。設定は config.json の `ai.compactDisplay` (`both` / `rotate` / `click`)
- **スキン** — ウィジェットの見た目を差し替える機能 (⚙ の「スキン」。2.6.0〜。詳しくは「[スキン](#スキン)」)。組み込みは 4 種類 (朱罫帳 / 計測票 FIELDNOTE / Orbital Zero-G / 紙テープ)、`skin.json` と `skin.css` の 2 ファイルで自作でき、zip でインポートもできる。選ばなければ従来のデザインのまま
- **フレームレスウィンドウ** — タイトルバーなしのコンパクトなデザイン、ドラッグで移動可能。角は DWM で丸めている (Windows 11 以降)
- **表示モード** — 通常 / コンパクトの 2 段階 + タスクバー格納。コンパクト表示は Windows サイドバーガジェット相当の幅 (130px) に縮み、フォントと余白も一段階小さくなる。収まらないセクション名は `Network` → `Net`、`Ethernet` → `LAN` のように短縮表示へ切り替わる。コンパクト時の切替ボタンは色と形が変わり、tooltip も「フル表示」に切り替わる
- **モードごとの位置記憶** — コンパクト化した位置を覚え、次にコンパクト化したとき同じ位置に出す。フル表示に戻すときはコンパクト化する直前の位置に戻る
- **設定 (⚙)** — 別ウィンドウ（広い設定ウィンドウ）から以下を設定。変更はウィジェットに即座に反映される
  - 配色テーマ (ダーク / ライト / システム追従)
  - スキン (見た目の差し替え。選択・インポート・削除・「コピーして編集」)
  - 透過モード
  - 電源モードの切替 (ON/OFF。既定 OFF)
  - CPU コア番号の表示 (0 始まり / 1 始まり)
  - タスクバー表示 (アイコンのみ / CPU 使用率 / AI 使用量)
  - 区画の表示と順序 (CPU・メモリ・GPU・NPU・Wi-Fi/Ethernet・AI を個別に表示/非表示にし、▲▼ で並べ替え。既定はすべて表示。GPU と NPU の両方を OFF にすると収集も停止)
  - AI 使用量 (ON/OFF、Claude / Codex、リセット表示、トレイに出すサービス、取得間隔・通知、ログアウト)
  - 起動とショートカット (スタートメニュー / スタートアップへのショートカットの登録と削除。チェックで作成、外すと削除)
- **システムトレイ (常時表示)** — 起動中は常にトレイアイコンを表示。`_` ボタンでウィンドウだけを格納でき、アイコンはそのまま残る。アイコンの左クリックで、格納と表示を切り替えられる。トレイ設定が「CPU 使用率」の場合はアイコンに使用率を描画し、下端の帯が、クロックのバーと同じ規則で、ベースクロックとの差で決まる色 (-10% 〜 +20%: 青 / -11% 以下: 緑 / +21% 以上: オレンジ) に変化する。ツールチップで概要確認。「AI 使用量」を選ぶと、角丸四角のアイコンに 5 時間枠の使用率 (数字) と 7 日枠のペース判定 (背景色: 緑 / 琥珀 / 赤) を表示する
- **常に前面表示 (ピン留め)** — ワンクリックで最前面に固定
- **ウィンドウリサイズ** — 端をドラッグしてサイズ変更可能
- **IME Composition Window の自動復旧** — MS-IME の変換ウィンドウが画面左上に張り付く不具合を WinEvent Hook で検知し、IME コンテキストのリセット等で自動復旧 (v1.5.0〜)
- **DPI 対応** — 高 DPI ディスプレイでも正しくスケーリング
- **設定の永続化** — ウィンドウサイズ・モードごとの位置・各種設定を `%LOCALAPPDATA%\widget-go\config.json` に保存。起動時は前回終了したモード (フル / コンパクト) と、そのモードで最後にいた位置から始まる (位置の記憶が無い初回は画面右下)

## 必要環境

- Windows 10 以降 (GPU/NPU の表示には Windows 10 version 2004 以降が必要。`D3DKMTEnumAdapters3` を利用できない古い OS では GPU/NPU の表示のみ無効)
- GPU の表示には WDDM 2.0 以上のドライバ、NPU の表示には MCDM 対応ドライバが必要 (NPU は DXCore の NPU 属性で判定)
- [WebView2 Runtime](https://developer.microsoft.com/ja-jp/microsoft-edge/webview2/) (Windows 11 ではプリインストール済み)
- AI 使用量を使う場合: claude.ai（Claude）と chatgpt.com（Codex）のアカウント。アプリ内でログインする (Claude Code / Codex の CLI は不要)
- Go 1.25 以降 (ビルドする場合)

## ビルド

```bash
go build -ldflags "-H windowsgui" -o system-widget.exe .
```

`-H windowsgui` フラグによりコンソールウィンドウが表示されません。

## 実行

```bash
./system-widget.exe
```

起動時は前回終了したモード (フル / コンパクト) で、そのモードで最後にいた位置に配置されます。位置の記憶が無い初回は、作業領域 (タスクバーを除いた画面領域) の右下にマージンを取って配置します。フル表示の幅は前回リサイズした値を復元します。

## 使い方

| 操作 | 説明 |
|------|------|
| ドラッグ | ウィンドウを移動 (離した時点で現在のモードの位置として保存) |
| 端をドラッグ | ウィンドウをリサイズ (離した時点でサイズを保存) |
| 📌 ボタン | 常に前面に表示をトグル |
| ⚙ ボタン | 設定ウィンドウ (別ウィンドウ。表示 / 区画 / AI 使用量 / 起動とショートカット) を開く。開いている間に押すと前面に出る。Esc か × で閉じる |
| ▬ ⇄ ▢ ボタン | コンパクト表示 (130px 幅) とフル表示を切替。それぞれ前回の位置に戻る。コンパクト時は青背景 `▢` になり tooltip が「フル表示」に |
| `_` ボタン | タスクバー (システムトレイ) に格納 |
| Wi-Fi/Ethernet セクション クリック | ネットワーク トラフィック表示と反転 |
| Disk セクション クリック | 使用量 (表) と I/O (裏) を反転 |
| 各見出し右端の ▼ | 区画を折りたたみ / 展開 (CPU・メモリ・Disk・GPU・NPU・Wi-Fi・AI)。Wi-Fi と Disk は区画のクリックで反転するため、折りたたみは ▼ のみ。折りたたむと表に戻る |
| AI 見出しの ↻ | AI 使用量を今すぐ取得し直す |
| トレイアイコン 左クリック | 表示中ならトレイへ格納 (最小化)、格納中なら表示して前面に出す (クリックのたびに切替)。他のウィンドウの陰になっているだけのときも、いったん格納されるので、もう一度クリックする |
| トレイアイコン 右クリック | バージョン表示と「終了」のメニューを開く。AI 使用量が ON のときは「AI 使用量を更新」「Claude / Codex にログイン…」(未ログインのときだけ)「AI 通知のテスト」も出る |

| 項目 | 値 | 説明 |
|------|------|------|
| テーマ | ダーク / ライト / システム | システムは `prefers-color-scheme` に追従 |
| スキン | デフォルト / 組み込み 4 種 / 利用者スキン (既定はデフォルト) | ウィジェット本体の見た目を差し替える。テーマ・透過モードとは独立に選べる。設定ウィンドウ自体には適用しない。「インポート…」で zip を取り込み、「スキンフォルダを開く」で `skins\` を開き、「再読み込み」で一覧と `skin.css` の編集を反映する。組み込みは「コピーして編集」で複製でき、利用者スキンは「削除」できる。読み込めなかったスキンは、理由つきでカードの下に出る。詳しくは「[スキン](#スキン)」 |

| 電源モードの切替 | チェック (既定 OFF) | ON にすると、CPU 区画のスライダーで Windows の電源モード (最適な電力効率 / バランス / 最適なパフォーマンス) を切り替えられる。OFF (既定) のときは電源モードの読み取りも切り替えも行わず、Windows の設定・制御のままになる。スライダーは隠れる。クロックのバーとトレイの帯の色は、この設定にかかわらず、ベースクロックとの差で決まる |
| CPU Core 番号 | 0 から / 1 から | コアラベルの起点番号を切替 |
| Disk の I/O 表示 | 数値 / グラフ (既定は数値) | Disk 区画の裏面 (クリックで反転) の見せ方。数値: アクティブな時間のバーと読み取り / 書き込み速度。グラフ: 読み取り / 書き込みの折れ線 (直近 2 分、縦軸は最低 1 MB/s)。見出しの値はどちらもアクティブな時間。`config.json` の `diskIoView` (`number` / `graph`) |
| タスクバー | アイコンのみ / CPU 使用率 / AI 使用量 | CPU 使用率: トレイアイコンを 5×7 ドットフォントで CPU % に差替。下端にアクセント帯を描画 (ベースクロックとの差で色が決まる。クロックのバーと同じ規則)。AI 使用量: 角丸四角に 5 時間枠の使用率と 7 日枠のペース色 (AI 使用量が ON のときだけ選べる。選んだまま OFF にすると、保存値は保たれ、表示だけアイコンのみになる) |
| 区画の表示と順序 | 各区画 (CPU / メモリ / Disk / GPU / NPU / Wi-Fi・Ethernet / AI 使用量) のチェックと ▲▼ | チェックを外した区画は画面から消え、残りが詰めて表示される (既定はすべて表示)。▲▼ で並べ替え (既定は CPU → メモリ → Disk → GPU → NPU → Wi-Fi → AI)。非表示の区画も順番は保たれる。GPU と NPU の両方を OFF にすると収集も停止。AI 使用量のチェックは「AI 使用量を表示」と同じ設定。v2.0.1 以前に「GPU/NPU を表示」を OFF にしていた場合は、GPU と NPU が非表示に引き継がれる |
| AI 使用量を表示 | ON / OFF (既定 OFF) | ON にすると認証用の WebView2 を起動して取得を始める。OFF にすると破棄して解放する |
| Claude / Codex | ON / OFF | 取得する側。両方 OFF にしても 1 つは有効に戻る |
| 5 時間枠のリセット表示 | 日時 / 残り時間 | 5 時間枠のリセット時刻の表示形式 |
| 7 日枠のトレイ配色ペース | 7 日按分 (既定) / 5 日按分 / 按分なし | トレイアイコンの背景色 (緑 / 琥珀 / 赤) を決める基準。按分は 7 日枠の経過日数に応じて 60% / 80% の閾値を縮める (7 日按分は N/7 日、5 日按分は N/5 日)。按分なしは固定の 60% / 80% |
| トレイに出すサービス | Claude / Codex | AI 使用量のトレイアイコンに出す側 (両方有効なときだけ選べる。既定は Claude) |
| 取得・通知・アカウント | 取得間隔 (60〜3600 秒、既定 300)、障害監視の間隔、通知 3 種、ログアウト | 通知は使用量 60% / 80% の到達、追加利用枠、サービス障害 (既定すべて ON) |
| スタートメニュー | チェック | ON にすると、スタートメニューのプログラム一覧に `system-widget.lnk` を保存する。OFF にすると削除する。状態はファイルの有無で決まる (設定ファイルには保存しない)。リンク先は今動いている実行ファイルで、画面に表示する。リンク先が違うショートカットがあるときは警告を出し (自動では書き換えない)、「今のアプリに更新」で上書きできる |
| スタートアップ | チェック | ON にすると、スタートアップ (ログイン時の自動起動) に `system-widget.lnk` を保存する。OFF にすると削除する。それ以外はスタートメニューと同じ |

## AI 使用量 (Claude / Codex)

v2.0.0 で、ClaudeMonitor の機能を取り込みました。

1. ⚙ → 「AI 使用量」で「AI 使用量を表示して取得する」を ON にすると、ウィンドウの下に「AI 使用量」の区画が出ます (既定は折りたたみで、見出しの下に Claude / Codex の使用率が 1 行ずつ、計 2 行で出ます)。▼ で展開します。
2. 初回は「未ログイン」と出るので、「ログイン」ボタン (またはトレイの右クリックメニュー) からログイン画面を開き、アプリ内でログインします。ログインが済むと、数秒で自動で閉じて値が出ます。Cookie は専用の WebView2 (後述の `AuthWebView2` など) に保存され、次回からは自動で再認証されます。
3. 5 時間枠・7 日枠の使用率とリセット時刻、プラン、追加利用枠 (Claude) / クレジット残高 (Codex)、サービス障害 (進行中のインシデントがあるとき) を表示します。使用量は既定で 5 分ごとに取得します。

- **旧 ClaudeMonitor からの引き継ぎ**: 初めて ON にしたとき、旧 ClaudeMonitor の認証データ (`%LOCALAPPDATA%\ClaudeMonitor\AuthWebView2` と `CodexAuthWebView2`) が見つかれば、Cookie とその復号に使う鍵だけをコピーして、ログイン済みの状態で始めます。コピー元は変更しません (ClaudeMonitor は引き続き単体で使えます)。ClaudeMonitor を起動したままだと、Cookie がロックされて引き継げないことがあります。その場合は ClaudeMonitor を終了してから、AI 使用量を OFF → ON にしてください。引き継ぎは 1 回だけで、ログアウトしても元には戻りません。
- **ログアウト**: ⚙ の「AI 使用量」の「アカウント」から、サービスごとにログアウトできます。アプリを再起動せず、そのサービスの認証データ (HttpOnly の Cookie を含む) をすべて消します。サーバー側のセッションは無効化されません。
- **通知**: 使用量が 60% / 80% に達したとき、追加利用枠が 60% / 80% に達したとき、サービス障害が新しく検出されたときに、Windows の通知 (バルーン) を出します。起動直後の最初の取得は基準値として扱い、通知しません。トレイの右クリックメニューの「AI 通知のテスト」で、通知の経路を確認できます。
- **メモリ**: 認証用に WebView2 を、有効なサービスごとに 1 つ起動します。実測では、未ログイン画面で、Claude で約 +430MB、Claude と Codex の両方で約 +590MB でした (ログイン後の値は未計測)。使わないときは OFF のままにするか、片方だけ有効にしてください。OFF にすると、約 1 秒でこれらを破棄して解放します。
- **ClaudeMonitor と同時に起動すると**、同じサービスへの取得が二重になります (読み取りのみで、実害はありません)。
- **注意**: 使用量の取得は、claude.ai と chatgpt.com の公式にドキュメント化されていない内部 API を使います。サービス側の仕様変更で、動かなくなる可能性があります。Claude Code / Codex の CLI や、その認証ファイルには依存せず、読み書きもしません。
- 診断ログは `%LOCALAPPDATA%\widget-go\notify.log` (1MiB を超えると、起動時に `notify.log.1` へ退避) に残ります。

## スキン

ウィジェット本体の見た目を差し替える機能です (2.6.0〜)。作り方の詳細 (フォルダ構成、`skin.json` の全フィールド、CSS 変数の一覧、実 DOM のクラス、サンプル、トラブルシュート) は [docs/skin-spec.md](docs/skin-spec.md) にまとめています。

1. ⚙ → 「スキン」で選びます。組み込みは「朱罫帳」「計測票 FIELDNOTE」「Orbital Zero-G」「紙テープ」の 4 種類で、「デフォルト」は従来のデザインです (既定)。選択はテーマ (ダーク / ライト / システム)・透過モードとは独立で、スキンはダークとライトの両方を持ちます。
2. 自作するには、「コピーして編集」で組み込みスキンを `%LOCALAPPDATA%\widget-go\skins\<id>-copy\` に複製し、「スキンフォルダを開く」で `skin.css` を編集して「再読み込み」を押します。`skin.json` と `skin.css` を入れた zip を「インポート…」で取り込むこともできます (取り込んだだけでは有効になりません)。
3. 読み込めなかったスキンは、一覧には出ず、フォルダ名と理由がカードの下に出ます。有効にしていたスキンが壊れたときは、画面はデフォルトに戻ります。

- **安全性**: スキンは CSS だけで、スクリプトは含められません。CSS は読み込み時に検査し (UTF-8、256 KiB 以下、`@import` と、`data:image/` 以外の `url()` を禁止、など)、zip は展開サイズ・エントリ数・パス (zip-slip) を検査します。さらにウィジェットの CSP が、外部のフォント・画像・通信を遮断します (使えるのは `data:image/` の埋め込み画像と、PC に入っているフォントだけ)。第三者のスキンは見た目を変えられますが、スクリプトは実行されず、外部への通信も CSP が遮断します。
- スキンを選ばない (デフォルト) ときは、従来どおりで、スキンの CSS は何も読み込みません。
- スキンの適用先はウィジェット本体だけです。設定ウィンドウは、従来どおりテーマだけで決まります。

## アーキテクチャ

ローカル HTTP サーバーをバックグラウンドで起動し、WebView2 がそのサーバーから配信される HTML/CSS/JS を描画するという構成です。

- **バックグラウンドコレクター** — CPU/クロック/メモリ/ネットワークトラフィック/GPU/NPU は 2 秒間隔、Wi-Fi/Ethernet は 3 秒間隔でキャッシュを更新
- **GPU/NPU のデータソース** — Windows 標準の D3DKMT でアダプタを列挙し、DXCore の NPU 属性で種別を判定。使用率とメモリは PDH の `GPU Engine`・`GPU Adapter Memory` カウンタから取得する。ベンダーに依存せず、タスクマネージャーと同じデータソースを使用
- **フロントエンド** — 2 秒間隔で `/api/system` をポーリングし UI を更新
- **ウィンドウ制御** — Win32 API を直接呼び出してフレームレス化・ドラッグ・リサイズ・トレイを実現。角丸は DWM (`DWMWA_WINDOW_CORNER_PREFERENCE`) に任せる — 枠なしウィンドウでは CSS の `border-radius` だと角の外側にコンテナの背景が残るため
- **AI 使用量** — Claude と Codex それぞれに、画面外 (-32000,-32000) に置いた専用の WebView2 を持ち、ログイン済みの Cookie を使ってページ内から内部 API を呼ぶ。Go 側は UI スレッド (メイン WebView の Dispatch) 経由でのみ操作する。ON にしたときに生成し、OFF で破棄して解放する
- **ウィンドウ位置の記憶** — 幅の切替は右端固定、高さの自動調整は下端固定で行うため、モードごとの位置は左上ではなく右下で保持する。こうするとリサイズの前後どちらで復元が走っても同じ位置に収束する

## 設定ファイルの保存場所

起動時に以下のパスを作成し、ここに設定・WebView2 ユーザーデータを保存します。

```
%LOCALAPPDATA%\widget-go\
├── config.json       # ウィンドウサイズ・モードごとの位置・テーマ・スキン (skin)・透過・Core 番号・トレイ表示モード・AI 使用量の設定 (ai)・区画の折りたたみ (collapsed) など
├── skins\            # 利用者スキン (<フォルダ名>\skin.json と skin.css)。インポート・コピーで作られる。組み込みスキンは exe に同梱
├── WebView2\         # WebView2 ランタイムのユーザーデータ (キャッシュ等)
├── AuthWebView2\     # Claude のログイン情報 (AI 使用量を ON にしたときに作られる)
├── CodexAuthWebView2\ # Codex (ChatGPT) のログイン情報 (同上)
├── AuthWebView2.migrated / CodexAuthWebView2.migrated  # 旧 ClaudeMonitor からの引き継ぎを済ませた印
└── notify.log        # AI 使用量の診断ログ (1MiB 超で notify.log.1 へ退避)
```

`config.json` は変更のたびに原子的に書き込まれる (`.tmp` → `rename`) ため、`os.Exit` やプロセス強制終了でも設定の欠落が起きません。

## アンインストール

1. **アプリを終了** — トレイアイコンを右クリック → 「終了」を選択 (トレイアイコンは起動中つねに表示されている)
2. **実行ファイルを削除** — 任意の場所に置いた `system-widget.exe` を削除
3. **設定・WebView2 データを削除** — エクスプローラのアドレスバーに `%LOCALAPPDATA%\widget-go` を入れて開き、フォルダごと削除 (AI 使用量を使っていた場合は、Claude / Codex のログイン情報 `AuthWebView2` と `CodexAuthWebView2` も一緒に消えます)
4. **スタートメニュー / スタートアップへの登録を解除** — 設定ウィンドウの「起動とショートカット」でチェックを外す (`system-widget.lnk` が削除される)。アプリを削除した後は、`Win + R` → `shell:startup` と `shell:programs` で開くフォルダの `system-widget.lnk` (または、手で置いたショートカット) を削除

> 多重起動防止に使用しているミューテックス (`Global\widget-go-single-instance-mutex`) はプロセス終了時に自動解放されます。レジストリは使用しません。

## 変更履歴

### 未リリース

- **起動時に前回のモードと位置を復元する** (#43) — コンパクト表示で終了しても、次の起動がフル表示に戻ってしまっていた。前回終了したモード (フル / コンパクト) の幅で、そのモードで最後にいた位置から始める。位置の記憶が無い初回は従来どおり画面右下。トレイ格納中に終了した場合は、格納前のモードで始まる。起動直後は復元が済むまで位置を保存しない (go-webview2 の初期化が位置を既定に戻す間に、前回の記憶を上書きしないため)。v1.9.2 の「起動時は常にフル表示・画面右下」の仕様を変更
- **Disk 区画を追加** (#44) — 固定ドライブの合計使用率・ドライブ別の使用量・Disk I/O (アクティブな時間 / 読み取り / 書き込み) を表示する新しい区画。既定で表示、⚙ の区画の一覧で非表示・並べ替え・折りたたみができる。容量は `GetDiskFreeSpaceEx` (固定ドライブだけ。Google Drive for desktop のようにディスク領域を持たない仮想ドライブは除く。10 秒ごと、別の goroutine)、I/O は PDH の `PhysicalDisk(_Total)` (`% Idle Time` から「アクティブな時間」= 100 − Idle を算出。2 秒ごと)。非表示の間は収集しない。保存済みの区画の並びに `disk` が無い既存の設定では、メモリの直後に入る。診断用に `cmd/diskprobe` を追加
- **Disk 区画をクリックで反転し、I/O を数値かグラフで表示** (#44) — Wi-Fi / Ethernet 区画と同じ作り (`.wifi-section` + `.flip-card`) で、表は使用量、裏は I/O。I/O の見せ方は ⚙ の「Disk の I/O 表示」で「数値」(既定、アクティブな時間のバーと読み取り / 書き込み速度) か「グラフ」(読み取り / 書き込みの折れ線、直近 2 分) を選ぶ。設定は `config.json` の `diskIoView` (`number` / `graph`。キーが無い旧設定は `number`)。コンパクト表示と折りたたみ中は見出し 1 行で、表は合計使用率、裏はアクティブな時間。折りたたむと表に戻る。スキンは `.wifi-section` / `.flip-card` / `.net-canvas` の既存の規則がそのまま効く (グラフの色は `--net-rx` = 読み取り、`--net-tx` = 書き込み)。折れ線の描画は Network と共通化した。反転の状態は保存しない

### 1.3.0 (2026-04-17)

- **Wi-Fi 7 / Windows 11 新 netsh フォーマット対応** — Windows 11 build 26200 で `netsh wlan show interfaces` の出力フィールドが変わっており、BSSID と帯域が取れなくなっていたのを修正。
  - `BSSID` → `AP BSSID` 表記への改名に追随 (`HasPrefix` → `Contains` で "AP BSSID" も吸収)
  - 新フィールド `バンド` (ja) / `Band` (en) をパースし最優先で採用。Wi-Fi 6E/7 では 6 GHz と 2.4 GHz のチャネル番号が被るため、バンド行がないとチャネルだけでは帯域を決定できない
  - フォールバック帯域判定を 6 GHz 対応に拡張 (`ch >= 178` は UNII-8 上位として 6GHz 確定、`36-177` 5GHz、`1-14` 2.4GHz)
  - `バンド: 5 GHz` のような値を `5GHz` 形式に正規化する `normalizeBand` ヘルパを追加
- **前提条件**: `netsh wlan show interfaces` は Windows 11 で位置情報サービス ON が必須。グループポリシー `DisableLocation=1` が有効だと権限エラーで取得不能。
