# Store 掲載用画像

`screenshots/01-monitor.png` は2026-11-14に、Store向けビルドの実際のウィンドウを撮影したもの。1450×1080px。デスクトップ向けの最小寸法1366×768pxを満たす。

新規のStore用設定で、ネットワーク区画とAI機能をOFFにし、幅と拡大率を変更して撮影した。数値・機器名は実際の表示であり、モックデータ、広告の文字入れ、画像合成・内容の加工は行っていない。CPU・GPU等の機種や測定値は環境により異なる。

個人のアカウント、SSID、認証画面、個別のパスを含む画像は掲載用に使用しない。追加画像も、アプリの実際の画面を確認してから採用する。

ストアの300pxアイコンは、ビルド時に既存の`icon.ico`から生成する。アプリの既存の意匠を使用し、外部の画像素材や別サービスのロゴは追加しない。
