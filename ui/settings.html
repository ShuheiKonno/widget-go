    区画

    区画の表示と順序

    チェックで表示、▲▼ で並べ替えます。非表示の区画も順番は保たれます。Disk は固定ドライブの使用量と I/O を表示し、OFF にすると収集も止まります。GPU / NPU は搭載している PC でだけ表示され、両方を OFF にすると収集も止まります。AI 使用量は ON にすると取得を始めます。勤務時間とポモドーロは AI 使用量とは別の区画で、既定は非表示です（勤務時間は OFF にしても計測は止まらず、状態は保たれます。詳しい設定は「勤務時間」「ポモドーロ」のタブにあります）。

    電源モードの切替

    ON にすると、CPU 区画に電源モードのスライダーが出て、Windows の電源モードを切り替えられます。OFF（既定）のときは、電源モードの読み取りも切り替えも行わず、Windows の設定・制御のままです。スライダーは非表示です。クロックのバーとトレイの帯の色は、この設定にかかわらず、ベースクロックとの差で決まります（-10% 〜 +20%: 青、-11% 以下: 緑、+21% 以上: オレンジ）。

    集中モード 対象のアプリ（プロセス名。1 行に 1 つ）

    既定は Teams（新: ms-teams.exe / 旧: Teams.exe）と Outlook（新: olk.exe / 旧: OUTLOOK.EXE）です。ほかのアプリ（例: Slack.exe）も足せます。管理者権限で動いているアプリは操作できません（無視します）。

    通知は、Windows の「通知」の、アプリごとのスイッチ（HKCU の Notifications\Settings）を、集中の間だけ OFF にして、終わると元の値に戻します。この方法が、お使いの Windows / Teams / Outlook で効くかは、実機での確認が必要です（効かない場合は、ウィンドウを隠すだけになります）。着信の呼び出し音は止められません（Teams / Outlook 側の設定で調整してください）。

    集中中に隠れたものが見つからないときは、ウィジェットのポモドーロの「一時的に表示」か、トレイのアイコンの右クリックの「Teams / Outlook の表示を戻す」を使います。

    疎通

    監視先ホスト（最大 5 件）
    ✓ 保存しました

    監視先には FQDN（例: google.com）または IP アドレス（例: 8.8.8.8、192.168.1.1）を指定します。パケロス閾値または RTT 閾値を超えた場合に、ウィジェット上で赤文字表示になり、ポップアップ通知が出ます。ロスは直近 20 回のうちの失敗回数（例: 2/20）で表示し、2 回以上落ちていて率が閾値以上のときに警告します（20 回分そろっていれば 1 回 = 5%）。名前解決に失敗したホストはロスに数えず、「解決失敗」と表示します。
