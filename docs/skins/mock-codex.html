計測票FIELDNOTE — 静かな計器、読み取るための余白。

小さな計測票を、デスクトップの片隅に。独立した角丸カードを細い罫線でつながる一枚の紙へ変え、数値と目盛りを主役にします。全体は抑えた緑、AI は茶と緑。色に頼らず、区画番号と整列で読み分けます。

デザインノート

スキンは data-skin="fieldnote"。テーマのダーク／ライト／システム追従とは併存し、透過モードも独立して使えます。初期プレビューはライトです。

設定画面の既存デザインは維持し、「表示」にスキン選択を追加。右の操作で両サイズのテーマと透過を同時に確認できます。数値はすべてダミーです。

data-skin="default" はスキン差分なし。fieldnote の形状差分は角丸、区画の上罫線、余白、数値サイズと計測バー。クロックの色は現行どおりベースクロックとの差で決まり、この例の 3.62 / 2.20 GHz はオレンジです。ネットワーク裏面はモックのみインライン SVG を使用し、本体の canvas は維持する想定です。

透過 ON は背景のアルファだけ .72 に上書き。システム追従は prefers-color-scheme に連動します。追加番号 01–06 は既存 .section-icon の表現差分。設定画面への追加はスキンカードのみで、ウィンドウ全体は既存のテーマを使います。

外部フォント・画像・通信なし。スクリプトの nonce はこの単体モック用の固定値で、移植時は既存の __WIDGET_TOKEN__ に合わせて配信側で設定します。
