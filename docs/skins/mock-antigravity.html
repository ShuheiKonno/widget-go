🛰️ デザインノート — コンセプトと設計方針

1. コンセプト名と狙い

コンセプト名: 「Orbital Zero-G（軌道テレメトリ / 無重力計器盤）」（属性値: data-skin="orbital"）

宇宙船のフライトデッキ計器（テレメトリ HUD）と無重力空間の光学照準器を着想源としたスキンです。既存の HTML 構造を一切変更せず、CSS 変数の差し替えと [data-skin="orbital"] セレクタのみで「四隅のレチクル（照準ブラケット）」「16px 座標マイクログリッド」「目盛り付きセグメントゲージ」「イオンスラスター調のシアン＆アンバー発光値」を与え、デスクトップの片隅に無重力で浮かぶ精密計器盤へと昇華させます。

2. 既存テーマ・透過モードとの関係（完全併存）

  • テーマ（ダーク / ライト / システム追従）と併存: スキンは「造形・目盛り・タイポグラフィ・色相体系」を担い、テーマは「明暗パレット」を担う直交（2軸）設計です。ダーク時は深宇宙計器盤（#060b15 ベース）、ライト時は月面クリーンルーム計器盤（#f1f6fc ベース）として両立します。
  • 透過モードと併存: Go 側のウィンドウ透過（/api/transparent）および背景アルファ値低減とそのまま組み合わせて機能し、デスクトップ壁紙の上に HUD レチクルと目盛りゲージが浮かび上がります。

3. 実装への移行しやすさ

  • body（またはルート要素）に data-skin="orbital" を付与するだけで切り替わります（既定は属性なし or data-skin="default"）。
  • プログレスバーやコア別バーのセグメント目盛りは .progress-bar::after / .core-bar-container::after の repeating-linear-gradient で描画しているため、既存の JS（style.width / style.height 更新）に一切影響しません。
