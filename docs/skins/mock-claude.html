スキン案「朱罫帳」しゅけいちょう / Shukei-chō ・ Claude 案 ・ widget-go スキン機能のデザインモック

帳簿の朱罫を手がかりにした、静かで文字中心のスキン案です。以下の見た目はすべて data-skin="shukei" と CSS 変数の上書き（差分）だけで組んでいます。アプリのコードは変更していません。

デザインノート

コンセプト

朱罫帳（しゅけいちょう） — 和紙の帳簿に朱の罫線を引いたような、紙とインクの質感のスキン。ダークは「墨」、ライトは「和紙」。

狙い

  • 箱をやめて罫線にする: 常駐ウィジェットは区画が積み重なるので、カードの箱（背景＋枠＋角丸）を、朱の罫線 1 本に置き換えて視覚ノイズを減らす。
  • 数値を主役に、色は意味だけに: 灰色基調の中に、CPU＝朱、メモリ＝藍、GPU＝浅葱、NPU＝山吹のように、項目ごとの色を 1 色ずつだけ置く（グラデーションはやめてベタ塗り）。
  • 絵文字を判子に: 💻🧠🎮 などの絵文字は OS ごとに色や大きさが違い、全体の色味を壊す。漢字 1 字の判子（算・記・画・脳・網・智）に置き換え、スキンの色に揃える。
  • 目盛つきの細いバー: バーは 4 分割の切れ目を入れた細い線にして、「だいたい何割か」が一目で読めるようにする。ネットワークの裏面は方眼紙のグリッド。

既存のテーマ・透過モードとの関係 — 併存（置き換えない）

  • テーマ（ダーク / ライト / システム）と直交する 2 軸目。body.theme-light の付け外し（システム追従の判定を含む）は今のまま。スキンは body[data-skin] を足すだけで、「スキン × テーマ」の組み合わせごとに配色を持つ。朱罫帳は ダーク＝墨 / ライト＝和紙 の 2 通りを用意している（下の「ダーク」「ライト」の段）。
  • 透過モードとも併存。透過は CSS ではなく Go 側のウィンドウ全体のアルファ（setTransparent、ALPHA_TRANSPARENT = 160）なので、スキンとは無関係に効く（下の「透過モード」の段）。注意点は、--container-bg 自体を半透明にするスキンを作ると、透過モードと重なって二重に薄くなること。朱罫帳は現行どおり 0.97 を踏襲している。
  • 既定のスキンは default（現行の見た目、差分なし）。未知の値や未設定は default にフォールバックする。設定窓の「スキン」カードは「テーマ」と「透過モード」の間に置く（右の設定ウィンドウを参照）。

実装メモ（後日、採用時のため）

  • 詳細度の罠: body.theme-light と body[data-skin] は同じ詳細度 (0,1,1)。後に書いた方が勝つので、[data-skin=x] と [data-skin=x].theme-light を必ずペアで書き、ライト側にも全変数を列挙する。
  • サイズは既定と同じ: 余白・フォントサイズ・バーの高さは既定とほぼ同じ（バーは 5px → 4px、見出し数値は +1px）。コンパクト（幅 130px）でも溢れないことを、このモックで確認済み。高さは scheduleHeightAdjust が追従する。
  • canvas の色: ネットワークのグラフ色は JS 内の直書き。--net-rx / --net-tx を getComputedStyle で読むようにすると、スキンに追従できる（凡例の色は CSS だけで変わる）。
  • 折りたたみ・コンパクトの反転表示（.ai-rot など）は、同じ変数を使うので追加の対応は不要。設定窓は --accent だけがスキンで変わる。
  • 設定の保存先は config.json の skin 文字列を想定。
