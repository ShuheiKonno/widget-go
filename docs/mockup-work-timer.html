勤務時間タイマー区画の UI 案です。幅 230px / 130px は実寸で、スタイルは ui/index.html のものを流用しています。表示の計算（昼休みの停止・15 分切り下げ・黄/赤の判定）は仕様どおりこのページ内で動くので、下のスライダーで「現在時刻」を動かして確かめられます。区画は AI 使用量とは別の独立した区画で、設定の並べ替え・表示/非表示も個別です。

このモックで確認している仕様

  • 表示は 実勤務時間 (15分切り下げの時間)。例: 7:52 (7:45)。実勤務時間 = 現在 − 開始 − 昼休みとの重なり。
  • 昼休み中は増えない。止まっていることが分かるよう、数値・見出し・バーを灰色にする（黄/赤より優先。シナリオ「昼休み中」で確認）。開始時刻を昼休みの後にすれば控除ゼロ、前にすれば 1 時間引かれる。
  • 設定で「15 分切り下げの時間も表示する」を OFF にすると、見出しも大きな数字も実勤務時間だけ（例 7:52）になる。既定は ON。黄/赤の判定は、この設定にかかわらず実勤務時間で行う。
  • 開始の補正: 「勤務開始」を押すと、押した時刻 − 補正（既定 3 分）を開始時刻にする（ボタンにも「3分前から」と表示）。補正した日は開始の下に「押下 09:06 − 補正 3分」を表示。計測中は開始の横の − / + で 1 分ずつ微調整でき、手入力もできる。補正を 0 にすると従来どおり押した時刻から。手入力で開始したときは補正しない。
  • 黄色: 実勤務時間 ≥ 勤務時間（既定 7:45）。赤: 現在時刻 ≥ 22:00（既定）。赤が優先。終了後は終了時刻で判定して固定。
  • 操作: 未開始は「勤務開始」（または開始時刻を手入力して開始）、計測中は「勤務終了」「リセット」、終了後は「リセット」。
  • 実装では、この計算を Go の純関数（workTimerSnapshot）に移してテストします。モックの JS は仕様確認用です。
